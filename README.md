# Своя игра

Интерактивное приложение для проведения интеллектуальной игры в формате «Своя игра», управляемое хостом.

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm run server
```

3. Запустите dev-сервер (в другом терминале):
```bash
npm run dev
```

4. Откройте браузер по адресу, указанному в консоли (обычно `http://localhost:5173`)

## Сборка для продакшена

```bash
npm run build
npm run server:build
```

Собранные файлы будут в папке `dist` и `server/dist`.

## Основные возможности

### Настройка игры
- Выбор количества раундов (1-3)
- Настройка количества тем в каждом раунде (4-7)
- Добавление команд (до 12)
- Автоматическое сокращение названий команд до 3 букв

### Игровой процесс
- Сетка вопросов с номиналами
- Система сюрпризов (Кот в мешке, Аукцион, Вопрос-тост, Мгновенный подарок)
- Управление ответами команд хостом
- Автоматический подсчёт очков
- Рейтинговая таблица после каждого раунда

### Финальный раунд
- Выбор темы (команды вычеркивают темы по очереди)
- Ввод ставок через панель ведущего
- Финальный вопрос с таймером
- Подведение итогов с автоматическим пересчётом очков
- Аналитика по командам

## Технологии

- React 18
- TypeScript
- Vite
- React Router
- Express (Backend API)

## Структура проекта

```
src/
  ├── context/          # Контекст для управления состоянием игры
  ├── screens/          # Экраны приложения
  ├── components/       # Переиспользуемые компоненты
  ├── types.ts          # TypeScript типы
  ├── App.tsx           # Главный компонент
  └── main.tsx          # Точка входа

server/
  ├── routes/           # API маршруты
  ├── db/               # База данных (localStorage файлы)
  ├── types.ts          # TypeScript типы сервера
  └── server.ts         # Express сервер
```
